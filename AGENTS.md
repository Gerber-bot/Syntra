# Reglas para asistentes de desarrollo

- Antes de modificar, leer `README.md` y `docs/ARQUITECTURA_Y_REGLAS.md`.
- No inventar resultados de compilación ni tests.
- No implementar funciones no solicitadas para el sprint.
- No tocar directorios externos a este repositorio sin autorización.
- Advertir riesgos antes de comandos que alteren el equipo o borren datos.
- Mantener modelo offline-first, sin permisos de Internet por defecto, sin credenciales en el código.
- Desarrollar iterativamente con pruebas, documentación y migraciones de base de datos seguras.
- La IA no escribe datos deportivos sin confirmación explícita.
- Uso real de Gentle AI / ODD y Engram MCP cuando estén disponibles; no simular invocaciones.
